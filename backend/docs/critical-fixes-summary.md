## Deployment Notes

The security fixes require the following environment configuration:

### Development (Debug Mode)
```bash
DEBUG=True
SECRET_KEY=<auto-generated or set manually>
```

### Production
```bash
DEBUG=False
SECRET_KEY=<must be set to secure value>
```

Generate a secure secret key:
```bash
openssl rand -hex 32
```
